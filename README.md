E-Commerce Management System

Project Introduction

This is a console-based E-Commerce Management System developed using Core Java. It is an academic project created to practice Java programming and object-oriented programming concepts.

Features

- View Products
- Search Products
- Menu-driven console interface

Technologies Used

- Java
- Core Java
- Object-Oriented Programming (OOP)

How to Run the Project

1. Download or clone this repository.
2. Open the project in a Java IDE such as Eclipse or IntelliJ IDEA.
3. Open the "Main.java" file.
4. Run the program.

Project Purpose

The purpose of this project is to understand Java fundamentals and develop practical programming skills through a simple e-commerce application.
